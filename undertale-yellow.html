Guide d'Installation
01

Choix du format

• Si vous ne possédez pas le jeu : téléchargez le Jeu Complet Prêt à Jouer.
• Si vous possédez déjà la version originale : téléchargez le Patcheur Automatique.

02

Sous Linux & Steam Deck

Double-cliquez directement pour lancer. Sur Steam Deck, passez en mode Bureau, faites clic droit sur le fichier et choisissez « Ajouter à Steam » pour lancer en mode Gaming avec les contrôles intégrés.

03

Sous Windows 10 / 11

Démarrez le fichier exécutable. Si Windows SmartScreen s'affiche, cliquez sur « Informations complémentaires » puis sur « Exécuter quand même ».

04

En Jeu

Tous les dialogues, cinématiques, graphismes de combat et menus s'affichent immédiatement en français.
