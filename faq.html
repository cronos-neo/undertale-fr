Foire Aux Questions & Support

Réponses détaillées aux questions courantes concernant l'installation, Steam Deck, la compatibilité manette et les sauvegardes.

Sur Steam Deck, aucune commande complexe en terminal n'est requise :

  1. Passez en mode Bureau (Bouton Steam > Alimentation > Basculer vers le bureau).
  2. Téléchargez l'archive complète du jeu ou le Patcheur Linux.
  3. Extrayez l'archive dans votre dossier personnel (ex: /home/deck/Games/).
  4. Ouvrez Steam, cliquez sur « Ajouter un jeu » en bas à gauche > « Ajouter un jeu non-Steam » et sélectionnez l'exécutable.
  5. Revenez en mode Gaming : le jeu s'affiche directement dans votre bibliothèque avec la disposition manette activée.

Il s'agit d'un faux-positif habituel pour les applications open-source ou communautaires sans certificat d'entreprise commercial Microsoft payant. Le patcheur et nos archives sont garantis 100% sains et sans aucun composant indésirable. Pour lancer le programme : cliquez sur « Informations complémentaires » puis sur « Exécuter quand même ».

Le Jeu Complet Prêt à Jouer : Recommandé si vous n'avez pas le jeu de base ou si vous souhaitez une solution sans manipulation. Vous téléchargez l'archive, vous l'extrayez, et vous jouez immédiatement avec la traduction intégrée.

Le Patcheur Automatique : Recommandé si vous possédez déjà le jeu original anglais sur Steam ou Game Jolt. Il injecte les fichiers de traduction dans votre dossier existant sans modifier vos sauvegardes.

La compatibilité avec vos sauvegardes de la version originale anglaise est de 100%. Vous pouvez reprendre votre partie sans manipulation :

Undertale Yellow :
Linux / Steam Deck : ~/.config/Undertale_Yellow
Windows : %localappdata%/Undertale_Yellow

Undertale Red & Yellow :
Linux / Steam Deck : ~/.config/Undertale_Red_and_Yellow
Windows : %localappdata%/Undertale_Red_and_Yellow

Oui. Sous Windows, les manettes Xbox et compatibles XInput fonctionnent dès le branchement. Pour les manettes PlayStation (DualShock 4 / DualSense) et Nintendo Switch Pro, ou sur Linux, nous vous conseillons de lancer le jeu via Steam (en l'ajoutant comme jeu non-Steam) afin de profiter du système Steam Input et de la calibration des sticks.

Vos sauvegardes sont enregistrées dans un dossier système indépendant du dossier d'installation du jeu. Vous pouvez remplacer le dossier du jeu ou extraire une nouvelle version sans aucun risque pour votre progression, vos succès ou vos fins débloquées.

Pour les utilisateurs avancés, vous pouvez appliquer le patch .xdelta directement via le terminal Linux ou l'application Delta Patcher sous Windows :
xdelta3 -d -s data_original.win uty-fr-v0.5.0.xdelta data.win
